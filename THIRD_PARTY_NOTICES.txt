# Third-party notices

The original BLK Studio / blk2ply code retains the MIT license in `LICENSE`.
Dependencies are downloaded at configure time into ignored caches, not included
in first-party source packages. Downloaded code is not reformatted or modified.
Versions and SHA-256 checksums are pinned in cmake/dependencies.cmake and
mapping/native/dependencies.json. Full notices are installed with binaries.

Binary packages reproduce these full notices in `licenses/`. The first-party
`cmake/jxr_compat.h` adapter corrects pointer-width typedefs for Windows LLP64 in
the JPEG XR ANSI build and supplies empty annotation macros. The adapter does not
alter vendor source or the integer sample decoding algorithm.

Windows binaries in the local release are built with LLVM-MinGW. The converter
statically links its runtime; the registration helper also ships OpenMP, oneTBB,
libc++, and unwind runtime DLLs under `mapping/bin/`.
The relevant LLVM, MinGW-w64 and compiler runtime notices are included in
`licenses/toolchain/` in the supplied Windows package. CMake, Ninja, Python,
Playwright and lint tools are not bundled application runtimes. Python is also
used for the optional registration worker and is installed separately.

Registration packages are installed into a user-selected or private Python
environment, not bundled in the portable ZIP. Open3D 0.20.0 is MIT licensed;
NumPy and SciPy use the BSD 3-Clause license; Matplotlib uses its own PSF-based license.
Their transitive dependencies retain their own notices. Preserve those notices
if redistributing a prepared Python environment. See `mapping/requirements.txt`.

KISS-Matcher is configured for ROBIN **MAX_CORE** only. The adapter generates a
translation unit containing the upstream BSD core solver and an explicit error
for the unused max-clique entry point. It omits ROBIN's optional GPL PMC dependency;
no PMC source or binary is distributed. CMake supplies missing transitive standard
includes and MinGW link adjustments without rewriting downloaded sources. The
original project MIT license is unchanged. Eigen's unmodified corresponding
source is available at the pinned URL in the dependency manifest.
